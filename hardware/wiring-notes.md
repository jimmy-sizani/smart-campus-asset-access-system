# Hardware Wiring Notes

## Digital Inputs

| Signal | GPIO |
|---|---:|
| MSB / Button 2 | GP13 |
| Bit 1 / Button 1 | GP14 |
| LSB / Button 0 | GP15 |

## Outputs

| Component | GPIO |
|---|---:|
| Green LED | GP16 |
| Red LED | GP17 |
| Buzzer | GP18 |
| Servo signal | GP19 |

Confirm voltage and power requirements before connecting components. An externally powered servo may require a shared ground with the Pico.

Add the actual prototype wiring photograph or diagram to this folder before publishing.
